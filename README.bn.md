**git ছাড়াই GitHub-এ ফাইল প্রকাশ করুন — টোকেন-দক্ষ, গোপনীয়তা-নিরাপদ, মাল্টি-এজেন্ট, বহুভাষিক।**

`gh-publisher` হলো একটি এজেন্ট স্কিল, যা `gh` CLI + GitHub REST API (Contents / Git Database) ব্যবহার করে একটি স্থানীয় ডিরেক্টরিকে GitHub রিপোজিটরিতে প্রকাশ করে — git প্রয়োজন নেই। একটি পুনঃব্যবহারযোগ্য স্ক্রিপ্ট দিয়ে এটি খালি রিপো ইনিশিয়ালাইজ ও ব্যাচ কমিট সামলায়, ফলে এজেন্টরা পুরো API ফ্লো নতুন করে বের করার বদলে একটিমাত্র কমান্ডে পুশ করতে পারে। এটি **GitHub-এর সর্বাধিক ব্যবহৃত ১০টি ভাষা** (README অনুবাদ) প্রকাশ করে, আর স্থানীয় ওয়ার্কিং কপি আপনার পছন্দের ভাষায় থাকে।

## কেন এটি আলাদা

- **🚀 Git-মুক্ত পুশ** — git নেই এমন মেশিনেও কাজ করে; খালি রিপোজিটরি স্বয়ংক্রিয়ভাবে ইনিশিয়ালাইজ করে।
- **⚡ টোকেন-দক্ষ** — একটি `scripts/push.ps1` কমান্ডই গার্ড → স্ক্যান → ইনিশিয়ালাইজ → ব্যাচ কমিট → মাস্ক করা আউটপুট (একটি `PUSHED N files -> URL` লাইন) সম্পন্ন করে, কয়েক ডজন হাতে-লেখা API কলের বদলে।
- **🌍 টোকেন-দক্ষ অনুবাদ** — বহুভাষিক README-গুলো **ইনক্রিমেন্টাল-এডিট অনুবাদ** দিয়ে আপডেট হয় (সাবএজেন্টরা পুরনো অনুবাদের উপরে শুধু পরিবর্তিত প্যারাগ্রাফগুলো সম্পাদনা করে, সম্পূর্ণ পুনঃঅনুবাদ নয়): প্রায় ৭০-৯০% কম আউটপুট টোকেন, দ্রুততর, এবং পরিভাষা/শৈলী স্থিতিশীল থাকে।
- **🔒 গোপনীয়তা ও অ্যাকাউন্ট নিরাপত্তা** — টোকেন কেবল `gh` keyring-এ থাকে (কখনোই চ্যাট/লগ/ফাইলে নয়); পুশের আগে ফাইলগুলো সিক্রেট-স্ক্যান করা হয় (`github_pat_`, `ghp_`, `sk-`, প্রাইভেট কী…); আউটপুট মাস্ক করা হয়।
- **🛡️ ব্যক্তিগত-ডেটা গার্ড** — মেশিন-লোকাল প্রোফাইল (`local-profile.json` / `config.local.json`) **কখনোই** প্রকাশ করা যায় না: সোর্সে এমন কোনো ফাইল দেখা দিলেই পুশ বাতিল হয়ে যায়, অন্য কিছু চালানোর আগেই।
- **🗂️ মেশিন-লোকাল প্রোফাইল** — জটিল নেটওয়ার্কিংয়ের (যেমন hosts হাইজ্যাকিং) মেশিনে একটি `local-profile.json` অ্যাকাউন্ট, gh এন্ট্রি (একটি প্রক্সি-মোড শিম) এবং পরিচিত রিপো ম্যাপিংকে এক জায়গায় রাখে, ফলে পুশ করতে শুধু `-Profile` দিলেই হয় — অ্যাকাউন্ট / gh / রিপো খোঁজার দরকার থাকে না।
- **🔌 মাল্টি-এজেন্ট-অভিযোজ্য** — `pwsh` স্ক্রিপ্ট Windows/macOS/Linux-এ চলে; DSH / Codex / Claude Code ম্যাপিং নথিভুক্ত করা আছে; কোনো হার্ডকোড করা প্ল্যাটফর্ম টুলের নাম নেই।
- **🧩 স্বয়ংক্রিয় খালি-রিপো ইনিশিয়ালাইজ** — খালি রিপো শনাক্ত করে এবং ব্যাচ কমিটের আগে Contents API দিয়ে প্রথম ফাইল সিড করে।
- **🌍 বহুভাষিক প্রকাশ** — স্থানীয় ওয়ার্কিং কপি আপনার নির্বাচিত ভাষায় থাকে (ডিফল্ট চীনা); রিলিজে GitHub-এর সর্বাধিক ব্যবহৃত ১০টি ভাষার (en, zh-CN, hi, es, fr, ar, bn, pt, ru, ja) README অনুবাদ থাকে। দেখুন `references/i18n.md`।

## এটি কীভাবে কাজ করে

1. `pwsh -ExecutionPolicy Bypass -File scripts/push.ps1 -Source <dir> -Repo owner/repo -Message "msg" [-Profile <local-profile.json>] [-GhPath <path-to-gh.exe>] [-Languages en,zh-CN,hi,es,fr,ar,bn,pt,ru,ja]`
2. স্বয়ংক্রিয়ভাবে `gh` বাইনারি খুঁজে বের করে (`-GhPath` → PATH → সাধারণ ইনস্টল পাথ) এবং `GH_CONFIG_DIR` স্বয়ংক্রিয়ভাবে শনাক্ত করে — কোনো ম্যানুয়াল PATH/config সামঞ্জস্যের প্রয়োজন নেই। `-Profile` দিলে gh এন্ট্রি, কনফিগ ডির, রিপো (সোর্স ডির দিয়ে ম্যাচ করে) এবং ভাষাগুলো (`README.<lang>.md` থেকে স্বয়ংক্রিয়ভাবে শনাক্ত) নিজে থেকেই ঠিক হয়ে যায়।
3. **ব্যক্তিগত-ডেটা গার্ড** — সোর্সে `local-profile.json` / `config.local.json` থাকলে → বাতিল (এগুলো কখনোই প্রকাশ করা উচিত নয়)।
4. সিক্রেট স্ক্যান → যেকোনো কী/টোকেন প্যাটার্ন পেলে বাতিল করে (যদি না `-ForceSecret` দেওয়া হয়)।
5. ব্রাঞ্চ ref চেক করে খালি রিপো শনাক্ত করে (404 = খালি) → প্রয়োজনে প্রথম ফাইল সিড করে (Contents API)।
6. সব ফাইল ব্যাচ কমিট করে (Git Database API: blobs → tree → commit → ref)।
7. `PUSHED N files -> https://github.com/owner/repo` প্রিন্ট করে — আর কিছুই নয়। রিপো না থাকলে → একটি `gh repo create` ইঙ্গিত প্রিন্ট করে।
8. ঐচ্ছিক `-Languages` চেক: পুশের আগে প্রতিটি ভাষার ফাইল বিদ্যমান কিনা যাচাই করে (যেমন `README.hi.md`) এবং কোনোটি অনুপস্থিত থাকলে সতর্ক করে।

## বহুভাষিক প্রকাশ (স্থানীয় ভাষা + ১০টি রিলিজ ভাষা)

- **স্থানীয় ওয়ার্কিং কপি**: আপনার কনফিগার করা ভাষায় থাকে (zh বা en) — ইনস্টল করা স্কিল ডিরেক্টরির `config.local.json`-এ (ডিফল্ট `zh`)। পরিবর্তন করতে বলুন *"স্থানীয় ডিফল্ট ভাষা ইংরেজিতে পরিবর্তন করুন"*; স্থানীয় SKILL.md-ও সেই অনুযায়ী আপডেট হয়।
- **রিলিজ**: `SKILL.md` ইংরেজিতে থাকে (সার্বজনীন GitHub প্রাথমিক সংস্করণ), আর সর্বাধিক ব্যবহৃত ১০টি ভাষার জন্য `README.<lang>.md` প্রকাশিত হয়। ভাষার তালিকা, অনুবাদের নিয়ম এবং ট্রিগার-কন্ট্রাক্ট নোটের জন্য দেখুন `references/i18n.md` (সব ভাষার সংস্করণে একই `name` থাকে)।
- **টোকেন-দক্ষ নির্দিষ্ট পরিকল্পনা**: যেসব ভাষার অনুবাদ আগে থেকেই আছে সেগুলো ইনক্রিমেন্টাল-এডিট অনুবাদ দিয়ে আপডেট হয় (শুধু পরিবর্তিত প্যারাগ্রাফ সম্পাদনা — সম্পূর্ণ পুনঃঅনুবাদ নয়); প্রথমবারের ভাষা একটি পূর্ণাঙ্গ অনুবাদ পায় যা পরিভাষার ভিত্তি স্থাপন করে। দেখুন `references/i18n.md` §1.5।

## মেশিন-লোকাল প্রোফাইল (local-profile)

অ-মানক নেটওয়ার্কিংয়ের মেশিনে (যেমন একটি hosts ফাইল GitHub ডোমেইনগুলোকে 127.0.0.1-এ হাইজ্যাক করছে, সাথে একটি পোর্টেবল `gh` যাকে লোকাল প্রক্সি শিম দিয়ে চালাতে হয়), `E:\ds harness\gh\local-profile.json` মালিক, gh এন্ট্রি, কনফিগ ডির এবং পরিচিত রিপো ম্যাপিংকে এক জায়গায় রাখে। ফাইলটিতে `"never_publish": true` ফ্ল্যাগ দেওয়া থাকে — এটি কেবল মেশিনেই থাকে এবং কখনোই পুশ করা হয় না। যে কোনো কাজ যা এটি পড়ে/পরিবর্তন করে, তার আগে স্পষ্টভাবে গুরুত্বারোপ করে নিশ্চিতকরণ নেওয়া হয়।

## এনভায়রনমেন্ট সেলফ-চেক (প্রথম পুশের আগে একবার)

- `Get-Command gh` (অথবা স্ক্রিপ্টকে ইনস্টল পাথ স্বয়ংক্রিয়ভাবে শনাক্ত করতে দিন); না থাকলে: `winget install GitHub.cli`।

- `gh api repos/{owner}/{repo}` অথবা `gh repo list` ডেটা ফেরত দেয়।
